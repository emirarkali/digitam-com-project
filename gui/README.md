# MATLAB GUI

GUI will be developed using MATLAB App Designer.

Planned features:
- WAV file selection
- Microphone recording
- PCM bit selection (3, 4, 8)
- SNR selection (0–10 dB)
- Run simulation
- BER vs SNR plot
- QPSK constellation
- Original and reconstructed audio playback

Save the App Designer project here as Project7_GUI.mlapp.
